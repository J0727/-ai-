# 技术报告大纲

## 一、作品概述
- 项目名称：智汇研途 - AI科研辅助平台
- 一句话定位：基于多智能体协作 + RAG 的科研辅助系统
- 解决的问题：大模型幻觉、文献调研效率低、结论不可核验

## 二、需求分析
- 用户痛点：科研文献数量多、综述耗时，通用 AI 回答缺乏来源依据
- 目标用户：高校师生、科研工作者

## 三、系统设计
- 总体架构：前端（交互与可视化）→ 后端（FastAPI）→ 模型层（DeepSeek）＋ 向量库（ChromaDB）
- 多智能体分工：检索员（Retriever）、总结员（Summarizer）、批判员（Critic）
- RAG 检索流程：文档切片 → 向量化 → 相似度检索 → 增强生成

## 四、技术选型
- 前端：HTML + TailwindCSS + Font Awesome + Chart.js
- 后端：FastAPI
- 向量库：ChromaDB
- 大模型：DeepSeek Chat API

## 五、核心功能实现
- 聊天交互与消息渲染（Enter 发送、Shift+Enter 换行）
- 智能体工作流可视化（检索员/总结员/批判员状态动画）
- 引用来源分布甜甜圈图
- 真实大模型接入、超时重试与失败降级

## 六、测试与验证
- 功能测试用例与结果（见 docs/测试报告.md）
- 边界情况：空输入、超长输入、连续发送
- 真实 API 调用耗时与效果记录

## 七、创新点与总结
- 多智能体协作 + RAG 的透明可视化流程
- 失败自动降级，保证演示稳定
- 后续优化方向：接入真实 Embedding 模型、跨会话记忆、PDF 批量解析
