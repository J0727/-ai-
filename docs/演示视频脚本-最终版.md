## ⚠️ 录制前必做（5 分钟）

1. **双击启动后端**：`E:\传智杯作品\backend\启动后端.bat`
   - 看到黑窗口出现 `Uvicorn running on http://127.0.0.1:8000` 才算成功，**保持窗口开着**。
2. **浏览器打开前端**：`E:\传智杯作品\frontend\index.html`，按 `Ctrl+R` 刷新一次。
3. **准备一个 PDF**：建议用 `E:\传智杯作品\docs\技术文档.pdf`（8 页，解析稳定）。

> 💡 判断真实回答：会针对你问的具体内容作答；模板回复则是固定的"针对您的问题，建议从以下维度展开"。

## 一、口播稿（提词器版，照着念）

### 0:00 开场（15 秒）
大家好，我是 XXX，来自 XXX 学校。今天展示我的参赛作品——**智汇研途**，一个基于多智能体协作与 RAG 检索增强的 AI 科研辅助平台，覆盖从文献导入到写作辅助的完整流程。

### 0:15 界面总览（25 秒）
先看整体界面。【扫顶部】顶部是系统标题和模型状态指示灯；【扫左侧】左侧是课题管理和「**工具箱**」——所有科研工具都收在里面；【扫右侧】右侧是智能体工作流和引用来源分布图。

### 0:45 上传文献 + 问答溯源（45 秒）⭐核心
首先上传一篇文献。【点「工具箱」→「上传文献」，选技术文档.pdf】稍等片刻，系统会解析 PDF、切片并写入向量库——标准 PDF 和扫描件都能处理，扫描件会自动走 OCR。
现在我问一个只有文档里才有的问题：【输入「智汇研途的系统架构分为几层？」回车】。
可以看到回答下方出现了「**参考来源**」，标明了来自哪个文件、哪个片段——这就是问答溯源，让结论可核验、可追溯。

### 1:40 引用图谱 + 综述生成（45 秒）
【点「工具箱」→「引用图谱」】系统基于文献片段的相似度，构建了引用关系网络，红色高亮的就是「**基石节点**」，也就是最核心的文献片段。
【关闭，点「工具箱」→「文献综述」，输入「大模型在医疗诊断中的应用」】系统会基于已入库文献，自动生成领域综述，涵盖研究背景、方法流派、关键发现和未来方向。

### 2:30 写作辅助 + 翻译/润色/纠错（55 秒）
【点「工具箱」→「论文大纲」输入主题】系统生成完整的论文大纲，包含摘要、引言、相关工作、方法、实验设计、结论。
【点「工具箱」→「学术翻译」】输入一段中文，翻译成英文学术表达。
【点「工具箱」→「学术润色」】粘贴一句口语化的话，系统自动改成规范学术表达，并给出修改点清单。
【点「工具箱」→「文献纠错」】输入一条文献引用，系统去 **Crossref 真实数据库**校验，返回 3 条候选，你可以选择「替换为这条」「自定义」或「不替换」。

### 3:25 CSV 图表 + LaTeX 表格（30 秒）
【点「工具箱」→「CSV 图表」粘贴数据】系统自动解析数据并生成柱状图。
【点「工具箱」→「LaTeX 表格」粘贴同样数据】一键转成可直接编译的 LaTeX 表格代码。

### 3:55 arXiv 检索（25 秒）
【点「工具箱」→「arXiv 检索」输入 `transformer`】系统调用 arXiv 接口抓取论文并写入向量库，之后就可以就这些论文提问。网络不通时会显示离线示例，保证演示不中断。

### 4:20 PDF 版式阅读（20 秒）
【点「工具箱」→「PDF 阅读」选 PDF】用浏览器原生渲染，完整保留论文的原始排版，实现版式感知阅读。

### 4:40 交互细节（30 秒）
【新建课题】【齿轮设置】【空输入】【Shift+Enter】再演示几个边界细节：新建课题切换标题、设置面板可调参数、空输入会友好提示、Shift+Enter 换行不发送。

### 5:10 工程规范（30 秒）
【切 GitHub Commits】细粒度提交历史，从项目骨架到全功能，一步一步迭代，没有一次性上传。【展示目录】API Key 通过环境变量管理，.env 文件已被忽略，不会泄露。

### 5:40 技术总结（30 秒）
技术核心：多智能体流水线 + RAG 抗幻觉 + 问答溯源 + 从文献导入到写作辅助的完整闭环。后端提供 13 个接口，前端工具箱 11 项工具，全部可现场演示。

### 6:10 收尾（20 秒）
这就是我的作品——智汇研途。谢谢评委老师，欢迎提问。
