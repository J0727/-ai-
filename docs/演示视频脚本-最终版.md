# 演示视频脚本 · 最终版（真实大模型版）

> 官方要求：**5–8 分钟**、**MP4**、**≥1080p**、**普通话讲解**。本稿按 **6 分钟**设计。
> 本篇基于「**后端已跑通、能返回真实 DeepSeek 答案**」的版本，录制时请务必先启动后端。

---

## ⚠️ 录制前必做（否则会录成模拟回复）

1. **双击启动后端**：`E:\传智杯作品\backend\启动后端.bat`
   - 看到黑窗口出现 `Uvicorn running on http://127.0.0.1:8000` 才算成功。
2. **浏览器打开前端**：`E:\传智杯作品\frontend\index.html`
3. **刷新一次页面**（`Ctrl+R`），确保拿到最新代码。
4. **开录前先试发一条**，确认能收到**真实回答**（不是"深度分析"那种模板），再正式录。

> 💡 判断是否真实：真实回答会针对你问的具体内容作答（比如问"癌症"，就会讲癌症）；模板回复则是固定的"针对您的问题，建议从以下维度展开"。

## 一、纯口播稿（提词器版，照着念）

### 0:00 开场
大家好，我是 XXX，来自 XXX 学校。今天向大家展示我的参赛作品——**智汇研途**，一个基于多智能体协作与 RAG 检索增强的 AI 科研辅助平台。

### 0:15 界面总览
先看整体界面。【鼠标扫顶部】顶部是系统标题和模型状态指示灯；【扫左侧】左侧是课题管理，可以新建课题、查看历史项目；【扫右侧】右侧是我们最核心的亮点——智能体工作流面板，以及下方的引用来源分布图。

### 0:45 核心演示（真实调用）
现在我输入一个研究问题，回车发送。
【镜头拉近右侧】请大家注意看右侧面板：检索员先启动，接着是总结员，最后是批判员，三个智能体接力完成整个流程，每一步状态都实时可见。
同时，前端正在调用后端封装的**真实 DeepSeek 接口**——这不是本地写死的模拟，而是真实的大模型推理，返回的是针对我这个问题生成的回答。

### 1:30 真实回答展示
【鼠标指回复】可以看到，返回的是一段真实、有针对性的回答，实测一次大约 4.7 秒。整个过程从检索、总结到批判校验，都在右侧面板里可视化呈现。

### 2:00 交互细节
再演示几个交互细节。【点新建】点「新建研究课题」，可以切换标题、清空对话；【点齿轮】右上角齿轮打开设置面板，可以调整模型温度和后端地址；【空输入发送】如果输入为空直接发送，会友好提示「请输入你的问题」；【Shift+Enter】按 Shift+Enter 则是换行，不会发送。这些都是人工调试过的边界细节。

### 2:40 后端与接口
【切终端】后端使用 FastAPI 实现，这是启动日志。【打开 /docs】打开接口文档，可以看到四个接口：健康检查、对话、写入文献、检索文献。刚才前端调用的就是这里的对话接口。后端还做了 30 秒超时和指数退避重试，即使网络抖动也能自动重试。

### 3:40 RAG 检索
除了对话，后端还预留了 ChromaDB 向量库的检索接口。【/api/rag/ingest】先把文献片段写入向量库；【/api/rag/search】再按问题做语义检索召回。这就是 RAG 的核心思路：先查资料再生成，从源头抗幻觉。

### 4:20 工程规范
再来看工程规范。【切 GitHub Commits】GitHub 仓库里保留了完整的细粒度提交历史，从项目骨架、界面、交互、接入模型到文档，一步一步迭代，没有一次性上传。【展示目录】API Key 通过环境变量管理，.env 文件已被忽略，不会泄露到公开仓库。

### 5:00 技术总结
总结一下技术核心：第一，多智能体流水线，检索员找证据、总结员归纳、批判员校验，三层质检降低幻觉；第二，RAG 检索增强，先查真实文献再生成，让结论有据可查；第三，真实大模型接入与失败降级，保证展示稳定。配合工作流可视化，整个推理过程透明可追溯。

### 5:40 收尾
这就是我的作品——智汇研途。谢谢评委老师，欢迎提问。
