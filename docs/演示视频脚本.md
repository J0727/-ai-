# 演示视频脚本

## 时长：约 3 分钟

### 0:00 - 0:20 开场与定位
「大家好，这是我们参加传智杯的作品——智汇研途，一个基于多智能体协作的 AI 科研辅助平台。
针对科研文献调研耗时、大模型容易幻觉的问题，我们用检索员、总结员、批判员三个智能体分工协作，并结合 RAG 文献检索增强来提升结论的可信度。」

### 0:20 - 0:50 界面总览
「这是主界面：顶部是系统标题与模型状态；左侧是课题历史列表；中间是对话区；右侧是智能体工作流面板，实时展示三个智能体的运行状态，下方是引用来源分布图。」

### 0:50 - 1:40 核心功能演示
「我输入一个研究问题，按回车发送。可以看到右侧检索员、总结员、批判员依次亮起，展示完整的协作流程。前端优先调用后端真实 DeepSeek API 返回结果；后端未启动时会自动回退到模拟回复，保证演示稳定。」

### 1:40 - 2:20 后端与 RAG 展示
「后端使用 FastAPI 封装 DeepSeek API，包含超时与重试逻辑；同时集成 ChromaDB 向量库，提供文献检索接口。我们展示 /api/chat、/api/rag/ingest、/api/rag/search 三个接口，并打开 /docs 查看自动生成的接口文档。」

### 2:20 - 3:00 总结
「整个项目从项目骨架、到界面布局、再到交互逻辑、最后接入真实大模型，每一步都保留了细粒度的 Git 提交历史，完整呈现了从 0 到 1 的迭代轨迹。谢谢观看。」
