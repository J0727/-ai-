# 演示视频脚本（逐秒版）

> 目标时长 **6 分钟**（官方要求 5–8 分钟），分辨率 **1080p**，MP4 格式，普通话讲解。

---

## 一、录制前准备（先做完再开录）

### 1. 软件与环境
- **录屏工具**：OBS Studio（免费）或 Windows 自带 Xbox Game Bar（快捷键 `Win+G`）
- **分辨率**：1920×1080（1080p），帧率 30fps
- **录制对象**：Chrome 浏览器窗口，建议最大化
- **麦克风**：用耳机麦克风，环境保持安静
- **摄像头**（可选加分）：右下角画中画出镜

### 2. 提前打开的页面（用标签页切好，别临场找）
| 标签 | 内容 | 用途 |
|------|------|------|
| 标签1 | `frontend/index.html` | 主演示（必用） |
| 标签2 | `http://127.0.0.1:8000/docs` | 后端接口演示（需先跑通后端） |
| 标签3 | `https://github.com/J0727/-ai-` | 展示 Git 提交历史 |

### 3. 提前准备好要输入的问题（照着打，别临场想）
- 问题1（触发"检索"关键词）：`帮我检索并总结 Transformer 在 NLP 领域的最新进展`
- 问题2（触发"实验"关键词）：`如何设计实验对比 RAG 与普通大模型的效果`

### 4. 前端提前准备
- 打开 `index.html` 后**先刷新一次**，让欢迎语和右侧工作流动画加载完成，再开始录。

### 5. 关于「后端段落」的说明
- 段落 5、6 需要**后端服务已经跑起来**（要先装 Python 依赖 + `uvicorn main:app --reload`）。
- 如果录制时后端没跑通，**直接跳过段落 5、6**，用段落 7（代码讲解）+ 口播带过后端内容即可，不影响交片，总时长约 4.5 分钟，也在 5–8 分钟内。

## 二、逐秒脚本

### 🎬 段落 0 · 开场（0:00 – 0:15，15 秒）
- **画面**：作品首页 `index.html` 全屏，静止展示。
- **操作**：不动鼠标。
- **口播**：「大家好，我是 XXX，来自 XXX 学校。今天展示我的参赛作品——智汇研途，一个基于多智能体协作与 RAG 检索增强的 AI 科研辅助平台。」

### 🎬 段落 1 · 界面总览（0:15 – 0:45，30 秒）
- **0:15–0:22** 鼠标缓慢移到**顶部 Header**，圈一下系统标题「智汇研途」和绿色状态点。口播：「顶部是系统标题，和 DeepSeek 模型状态指示灯。」
- **0:22–0:32** 鼠标移到**左侧边栏**，指「新建研究课题」按钮和课题历史。口播：「左侧是课题管理，可以新建课题、查看历史项目。」
- **0:32–0:45** 鼠标移到**右侧面板**，重点圈「检索员 / 总结员 / 批判员」三张卡片和下方甜甜圈图。口播：「右侧这块是我们最核心的亮点——智能体工作流面板，接下来重点演示。」

### 🎬 段落 2 · 核心功能：一次完整的智能体协作（0:45 – 1:30，45 秒）⭐重点
- **0:45–0:55** 鼠标点进中间输入框，逐字输入问题1：`帮我检索并总结 Transformer 在 NLP 领域的最新进展`，然后按 **回车** 发送。
- **0:55–1:15** 镜头/鼠标**拉近右侧面板**，让观众看到三个智能体卡片**依次**变化：`等待` → `进行中`（紫色高亮 + 进度条走满）→ `已完成`（绿色）。这一步是全场最重要的画面，慢一点、别切走。
- **1:15–1:25** 鼠标回到**中间对话区**，指着「正在输入」的三个跳动小点 → AI 气泡弹出回复。
- **1:25–1:30** 鼠标在回复上滑动，指出分点结构。
- **口播**：「输入问题回车发送。注意看右侧——检索员先启动，接着总结员，最后批判员，三个智能体接力完成。整个过程可视化，评委能直接看到 AI 每一步在干什么，而不是一个黑盒。」

### 🎬 段落 3 · 换问题，展示关键词匹配（1:30 – 2:00，30 秒）
- **1:30–1:40** 再次点输入框，输入问题2：`如何设计实验对比 RAG 与普通大模型的效果`，按回车发送。
- **1:40–1:55** 右侧工作流再次跑一遍，中间弹出**不同内容**的回复（针对实验设计的回答）。
- **1:55–2:00** 鼠标指出这次回复内容和上次不一样。
- **口播**：「换一个偏实验设计的问题，系统会匹配不同关键词，给出针对性的结构化回答，不是千篇一律的模板。」

### 🎬 段落 4 · 交互细节（2:00 – 2:40，40 秒）
- **2:00–2:15** 点「新建研究课题」→ 弹窗输入 `大模型可解释性研究` → 回车。指出**标题切换了、聊天区清空了**。
- **2:15–2:25** 点右上角**齿轮**，打开设置弹窗，指出「模型温度、后端 API 地址都可调」，点取消关闭。
- **2:25–2:33** 演示**空输入**：输入框留空直接点「发送」，弹出提示「请输入你的问题！」。
- **2:33–2:40** 演示 **Shift+Enter**：在输入框里按 Shift+Enter 换行（不发送）。
- **口播**：「几个边界细节：新建课题、设置面板、空输入会友好提示、Shift+Enter 换行不发送。这些都是人工调试过的小细节。」

### 🎬 段落 5 · 后端与真实 API（2:40 – 3:40，60 秒）【需后端已启动】
- **2:40–2:50** 切到**终端**，展示 `uvicorn main:app --reload` 启动成功。
- **2:50–3:00** 打开 `http://127.0.0.1:8000/docs`，指出「FastAPI 自动生成的接口文档，有 /health、/api/chat、/api/rag/ingest、/api/rag/search 四个接口」。
- **3:00–3:20** 点 `/api/chat` → **Try it out** → 填入问题 → **Execute**，展示返回的真实结果。可补一句「这就是接的 DeepSeek 真实接口，实测一次约 4.7 秒」。
- **3:20–3:40** 口播补充：「后端做了超时重试和失败降级——即使评审现场网络不稳，前端也会自动降级到模拟回复，演示不会翻车。」

### 🎬 段落 6 · RAG 检索演示（3:40 – 4:20，40 秒）【需后端已启动】
- **3:40–3:55** 在 `/api/rag/ingest` 点 Try it out，写入一条文献片段，Execute。
- **3:55–4:10** 在 `/api/rag/search` 查询相关问题，Execute，展示召回的相关文献片段。
- **4:10–4:20** 口播：「这就是 RAG 的向量检索——先把文献写入 ChromaDB，再按语义召回，先查资料再生成，从源头抗幻觉。」

### 🎬 段落 7 · 工程规范（4:20 – 5:00，40 秒）
- **4:20–4:40** 切到 **GitHub 仓库**，点顶部 `Commits`，指出：「这是我们的细粒度提交历史，从项目骨架 → 界面 → 交互 → 接真模型 → 文档，一步步迭代，没有一次性上传。」
- **4:40–5:00** 展示仓库目录结构 + `.gitignore` + `backend/.env.example`，指出：「API Key 用环境变量管理，.env 已忽略，不会泄露到公开仓库。」
- **口播**：「工程规范上，我们保留了完整的细粒度 Git 提交历史，密钥用环境变量管理，仓库公开可复现。」

### 🎬 段落 8 · 技术深度讲解（5:00 – 5:40，40 秒）
- **画面**：切回首页定格（或展示一张架构图）。
- **口播**：「技术核心两点。第一，多智能体流水线——检索员找证据、总结员归纳、批判员校验，三层质检降低幻觉；第二，RAG 检索增强——先查真实文献再生成，让结论有据可查。配合工作流可视化，整个推理过程透明可追溯。」

### 🎬 段落 9 · 收尾（5:40 – 6:00，20 秒）
- **画面**：首页定格。
- **口播**：「这就是我的作品——智汇研途。谢谢评委老师，欢迎提问。」
