# 演示视频 · 录屏稿与操作脚本

> 官方要求：**5–8 分钟**、**MP4**、**≥1080p**、**普通话讲解**。本稿按 **6 分钟**设计。

---

## 使用建议（先看这个）

- **双屏/打印**：把「一、纯口播稿」放在一台设备或打印出来**照着念**；「二、逐秒操作脚本」放在另一处**照着点**。
- 两份内容**时间戳一一对应**，念到哪一段，操作就做到哪一段。
- 录制前先把「三、录制前准备」全部做完，再开录，避免中途卡壳。

## 一、纯口播稿（提词器版，照着念）

> 括号里的时间是「大概念到第几分钟」，不用精确对齐，自然一点更好。
> 【 】里是给操作的手势提示，念的时候不用念出来。

### 0:00 开场
大家好，我是 XXX，来自 XXX 学校。今天向大家展示我的参赛作品——**智汇研途**，一个基于多智能体协作与 RAG 检索增强的 AI 科研辅助平台。

### 0:15 界面总览
先看整体界面。【鼠标扫顶部】顶部是系统标题和模型状态指示灯；【扫左侧】左侧是课题管理，可以新建课题、查看历史项目；【扫右侧】右侧是我们最核心的亮点——智能体工作流面板，以及下方的引用来源分布图。

### 0:45 核心演示
现在我输入一个问题，回车发送。
【镜头拉近右侧】请大家注意看右侧面板：检索员先启动，接着是总结员，最后是批判员，三个智能体接力完成整个流程，每一步状态都实时可见。整个过程不是黑盒，评委能直接看到 AI 在做什么、做到哪一步。

### 1:30 换一个问题
我们再换一个偏实验设计的问题。【发送】系统会匹配不同关键词，给出针对性的结构化回答，而不是千篇一律的模板。

### 2:00 交互细节
再演示几个交互细节。【点新建】点「新建研究课题」，可以切换标题、清空对话；【点齿轮】右上角齿轮可以打开设置面板，调整模型温度和后端地址；【点发送】如果输入为空直接发送，会友好提示「请输入你的问题」；【按 Shift+Enter】按 Shift+Enter 则是换行，不会发送。这些都是人工调试过的边界细节。

### 2:40 后端与真实 API
后端我们使用 FastAPI 封装了 DeepSeek 真实接口。【切终端】这里是启动日志，【打开 /docs】打开接口文档可以看到四个接口：健康检查、对话、写入文献、检索文献。我们实际调用一次对话接口，【点 Execute】返回的是真实的大模型结果，实测一次大约 4.7 秒。后端还做了超时重试和失败降级，即使评审现场网络不稳，前端也会自动回退，演示不会翻车。

### 3:40 RAG 检索
除了对话，后端还集成了 ChromaDB 向量库。【/api/rag/ingest】这里演示文献写入——先把文献片段写入向量库；【/api/rag/search】再按问题检索召回相关文献。这就是 RAG 的核心：先查资料再生成，从源头抗幻觉。

### 4:20 工程规范
再来看工程规范。【切 GitHub Commits】GitHub 仓库里保留了完整的细粒度提交历史，从项目骨架、界面、交互、接入模型到文档，一步一步迭代，没有一次性上传。【展示目录】API Key 使用环境变量管理，.env 文件已被忽略，不会泄露。

### 5:00 技术总结
总结一下技术核心：第一，多智能体流水线，检索员找证据、总结员归纳、批判员校验，三层质检降低幻觉；第二，RAG 检索增强，先查真实文献再生成，让结论有据可查。配合工作流可视化，整个推理过程透明可追溯。

### 5:40 收尾
这就是我的作品——智汇研途。谢谢评委老师，欢迎提问。

## 二、逐秒操作脚本（照着点）

### 🎬 段落 0 · 开场（0:00 – 0:15）
- **画面**：作品首页 `index.html` 全屏，静止展示。
- **操作**：不动鼠标。
- **对应口播**：见「一、0:00 开场」。

### 🎬 段落 1 · 界面总览（0:15 – 0:45）
- **0:15–0:22** 鼠标缓慢移到**顶部 Header**，圈一下标题「智汇研途」和绿色状态点。
- **0:22–0:32** 鼠标移到**左侧边栏**，指「新建研究课题」按钮和课题历史。
- **0:32–0:45** 鼠标移到**右侧面板**，重点圈「检索员 / 总结员 / 批判员」三张卡片和下方图表。
- **对应口播**：见「一、0:15 界面总览」。

### 🎬 段落 2 · 核心功能（0:45 – 1:30）⭐最关键
- **0:45–0:55** 点中间输入框，逐字输入：`帮我检索并总结 Transformer 在 NLP 领域的最新进展`，按 **回车**。
- **0:55–1:15** **镜头/鼠标拉近右侧面板**，让三个智能体卡片**依次**：`等待` → `进行中`（紫色高亮 + 进度条走满）→ `已完成`（绿色）。**这一段是全场最重要的画面，慢一点、别切走。**
- **1:15–1:25** 鼠标回中间对话区，指「正在输入」的三个跳动小点 → AI 气泡弹出。
- **1:25–1:30** 鼠标在回复上滑动，指出分点结构。
- **对应口播**：见「一、0:45 核心演示」。

### 🎬 段落 3 · 换问题（1:30 – 2:00）
- **1:30–1:40** 再点输入框，输入：`如何设计实验对比 RAG 与普通大模型的效果`，按回车。

- **1:55–2:00** 鼠标指出这次回复和上次不一样。
- **对应口播**：见「一、1:30 换一个问题」。

### 🎬 段落 4 · 交互细节（2:00 – 2:40）
- **2:00–2:15** 点「新建研究课题」→ 弹窗输入 `大模型可解释性研究` → 回车。指出**标题切换、聊天清空**。
- **2:15–2:25** 点右上角**齿轮**，打开设置弹窗，指出可调项，点取消。
- **2:25–2:33** 演示**空输入**：留空直接点「发送」，弹出提示。
- **2:33–2:40** 演示 **Shift+Enter**：按 Shift+Enter 换行（不发送）。
- **对应口播**：见「一、2:00 交互细节」。

### 🎬 段落 5 · 后端与真实 API（2:40 – 3:40）【需后端已启动】
- **2:40–2:50** 切到**终端**，展示 `uvicorn main:app --reload` 启动成功。

## 三、录制前准备（开录前必须做完）

### 1. 录屏软件（二选一）
- **推荐**：OBS Studio（免费），点「开始录制」即可，输出 MP4。
- **备用**：Windows 自带 Xbox Game Bar（`Win+G`），点录制按钮（适合零基础）。

### 2. 录制参数
- 分辨率：**1920×1080（1080p）**
- 帧率：30fps
- 录制对象：Chrome 浏览器窗口，最大化
- 音频：用耳机麦克风，环境保持安静

### 3. 提前打开的标签页
| 标签 | 内容 | 用途 |
|------|------|------|
| 标签1 | `frontend/index.html` | 主演示（必用） |
| 标签2 | `http://127.0.0.1:8000/docs` | 后端接口（需先跑通后端） |
| 标签3 | `https://github.com/J0727/-ai-` | 展示 Git 历史 |

### 4. 提前打字练一遍
把下面两句**练到能盲打**，录的时候别低头找键：
- 问题1：`帮我检索并总结 Transformer 在 NLP 领域的最新进展`
- 问题2：`如何设计实验对比 RAG 与普通大模型的效果`

### 5. 打开前端后先刷新一次
让欢迎语和右侧工作流动画加载完，再开始录。

### 6. 关于「后端段落」（段落 5、6）
- 需要先装 Python 依赖并启动 `uvicorn main:app --reload`。
- **如果录的时候后端没跑通**：直接跳过段落 5、6，用段落 7 的代码讲解带过，总时长约 4.5 分钟，仍在 5–8 分钟内，不影响交片。

### 7. 摄像头（可选加分）
右下角画中画出镜，显得更正式。用 OBS 加「视频采集设备」即可。

## 四、录制小技巧

- 说话别太快，**每句话之间留半秒停顿**，后期好剪。
- 鼠标移动要**慢而稳**，别乱抖。
- 录错了别慌，**继续录**，后期剪掉重录的那一段即可。
- 一次录不完可以分段录，最后用剪映把几段拼起来。
- 建议录 **2 遍**，挑顺畅的那遍用。
