# 智汇研途 · 演示视频脚本（对话版）

> 适用：第九届传智杯 · AI 大模型创新应用挑战赛 · 省赛作品提交
> 时长目标：**6 分 05 秒**（要求 5–8 分钟）
> 分辨率：1920×1080 / 30fps / 中文解说

---

## 一、录制前准备清单

### 1. 环境准备

| 项 | 要求 |
|----|------|
| 演示地址 | `http://139.224.206.77:8000`（公网，已部署）|
| 演示账号 | `demo` / `demo123456` |
| 浏览器 | Chrome 或 Edge，**缩放 100%**，关掉书签栏 |
| 分辨率 | 窗口 1920×1080 全屏，任务栏隐藏 |
| 网络 | 有线优先，提前测一次响应速度 |
| 麦克风 | 外接或耳机，录制前试音，背景保持安静 |

### 2. 提前预跑一遍（很重要）

为了录制时不卡顿，正式录之前**按脚本顺序预跑一遍**，让缓存和网络预热：

- 检索一次 `transformer 在医学影像中的应用`
- 翻译一次 `卷积神经网络在图像识别中效果很好`
- 核验一次 DOI `10.1038/nature12373`

> 预跑后这些结果会命中缓存，正式录制响应更快。

### 3. 录制工具

- **录屏**：OBS Studio（推荐）或 Windows 自带 Xbox Game Bar（Win+G）
- **剪辑**：剪映专业版（免费，够用）
- OBS 设置：视频 1920×1080 / 30fps，麦克风 48kHz

### 第 2 段｜开场：讲清痛点（0:15 – 0:55）

**画面**：浏览器打开 `http://139.224.206.77:8000`，展示对话首页（左侧 17 项能力、中央三个主张卡片）

**操作**：
1. 鼠标缓慢划过左侧「全部能力」列表
2. 停在中央三张卡片上：**逐条溯源 / 独立复核 / 一致才显示**

**旁白**：
> 「这是我们做的科研助手。和常见的 AI 对话产品最大的区别是——
> 它不会直接给你一个看起来很专业的答案。
> 每一篇文献、每一个译名、每一句译文，都要先通过至少两条彼此独立的通道复核，
> 两次答案一致，才会显示给你；不一致的，会被移到「未通过核验」区，并且公示出来。
> 这就是首页这三句话：逐条溯源、独立复核、一致才显示。」

---

### 第 3 段｜场景一：文献检索与双通道核验（0:55 – 2:10）⭐ 核心

**画面**：输入框

**操作**：
1. 点击输入框，输入：
   ```
   检索 transformer 在医学影像中的应用
   ```
2. 回车发送

**画面过程**（让观众看到过程，不要快进）：
- 执行步骤逐步出现：`调用能力：全网文献检索` → `检索 4 个学术库` → `独立复核完成`
- 右侧溯源面板自动打开，展示每条文献的 DOI、来源、复核通道

**旁白**：
> 「第一个场景是文献检索。
> 表面上这只是一次搜索，实际上后台做了三件事：
> 第一，并行检索 Crossref、OpenAlex、Europe PMC、DOAJ 四个开放学术库；
> 第二，对每一条结果做去重和聚类；
> 第三，也是最关键的——对每一条结果做双通道复核：
> 通道一是用 DOI 直接去 Crossref 查注册记录，通道二是拿标题去其他库重新查一遍，
> 只有两条通道给出同一篇文献，它才会进入结论区。」

**操作**：鼠标悬停在「独立复核完成：N 条一致 / M 条剔除」这一行上

**旁白**：
> 「你可以看到这里写着几条一致、几条被剔除。
> 被剔除的不是删掉了，而是放在下面「未通过核验」区，你可以自己看它为什么没通过。」

**操作**：点击一条文献的「查看原文」链接（新标签打开后立刻切回）

**旁白**：
> 「每条结论都能点回原始出处，这就是可追溯。」

---

### 第 4 段｜场景二：翻译核验（2:10 – 3:20）⭐ 核心

**画面**：新建对话（点左上角「+ 新建对话」）

**操作**：输入
```
把这句话译成英语并核验：卷积神经网络在图像识别中效果很好
```
回车。

**画面过程**：
- 步骤条：`执行两次彼此独立的低温翻译` → `回译一致性复核 + 术语国标双向核验`
- 结果分两块：**权威术语** + **通过双译的句子**

**旁白**：
> 「第二个场景是学术翻译。翻译最容易出问题的不是语法，而是术语。
> 所以这里的做法是：先抽取句子里的专业术语，拿去「术语在线」——也就是全国科学技术名词审定委员会的官方库——
> 查国标审定译名，再用查到的英文反查一遍，双向对得上才算数。」

**操作**：鼠标指向结果中的 `卷积神经网络 → convolutional neural network · GB/T 41867—2022`

**旁白**：
> 「比如这里，「卷积神经网络」被确认对应 convolutional neural network，
> 而且给出了国标号 GB/T 41867—2022，你可以自己拿这个号去查。」

**操作**：鼠标移到下面整句译文

**旁白**：
> 「整句部分更严格：系统会让模型用两种彼此独立的方式各译一次，
> 一次逐句译、一次整篇译，然后逐句比对相似度，还要做一次回译——
> 把译文再译回中文，看能不能回到原意。
> 只有这几关都一致的句子，才会出现在上面这个「通过核验」区；
> 不一致的句子会进下面的未通过区，宁可不给你，也不给你一个可能是错的译文。」

---

### 第 5 段｜场景三：引用真伪核验（3:20 – 4:00）⭐ 差异点

**画面**：新建对话

**操作**：输入
```
核验这条引用：10.1038/nature12373
```
回车。

**旁白**：
> 「第三个场景，是很多人做文献综述时的刚需——引用真伪核验。
> 大模型最容易犯的错误就是编造一条看起来非常真实的参考文献。
> 这里我们把 DOI 直接拿到 Crossref 的注册记录里查：
> 注册记录里有的，才叫真的存在；查不到的，系统会明确告诉你查不到，而不是编一个标题给你。」

**操作**：展示结果中的标题、作者、期刊、年份

**旁白**：
> 「返回的标题、作者、年份都来自 Crossref 的原始记录，不是模型生成的。」

### 第 6 段｜场景四：安全机制（4:00 – 4:50）⭐ 加分项

**画面**：点击右上角「溯源面板」/ 左下角「安全策略已启用 → 查看」

**操作**：展示安全策略面板

**旁白**：
> 「除了严谨，我们还把安全做成了默认配置。
> 内容安全策略禁止加载任何外部脚本，并且启用了 Trusted Types，杜绝 DOM 型 XSS；
> 所有出网请求必须命中白名单，并且在解析后重新校验目标 IP，防止 SSRF 和 DNS 重绑定；
> 会话是 HMAC 签名的，带过期时间和随机数；接口按 IP 和会话双维度限流；
> 审计日志只记哈希，不记原文和密钥。」

**操作**（可选，若时间充裕）：在输入框输入
```
帮我编一篇不存在的 Nature 论文
```
展示系统拒绝

**旁白**：
> 「如果要求它编造文献，它不会照做，而是直接阻断并说明原因。」

## 三、剪辑与字幕规范

| 项 | 要求 |
|----|------|
| 分辨率 | 1920×1080，30fps |
| 码率 | ≥ 6 Mbps（H.264）|
| 音频 | AAC 192kbps，单声道即可 |
| 字幕 | 全程加**中文硬字幕**（评委可能在静音环境看）|
| 关键标注 | 在「一致才显示」「GB/T 41867—2022」「DOI 注册记录」处加**黄色方框 + 文字标注**，停留 2 秒 |
| 加速 | 只允许在「等待响应」的空档做 1.5 倍加速，**核验结果出现的那一帧必须原速** |
| 转场 | 段落之间用 0.5 秒淡入淡出，不要花哨特效 |

---

## 四、常见翻车点

| 问题 | 预防 |
|------|------|
| 录到一半网络超时 | 提前预跑，避开网络高峰 |
| 字幕挡住关键数字 | 字幕放在画面下方 10% 区域，避开结果区 |
| 旁白和画面对不上 | 先录音后剪片，或按「一段一录」分段录制 |
| 时长超 8 分钟 | 第六段（安全）可精简到 30 秒；第七段可压到 40 秒 |
| 忘记展示溯源链接 | 第三段和第五段必须点开一次原文/DOI |
